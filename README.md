# XX Cutscene Replacer
A simple CLT for replacing cutscenes in Genshin, ZZZ and HSR  
well, not yet tested for anything other than Genshin hah

## Usage
Install python, run:
```
git clone https://github.com/Epigeos-com/XXCR
pip install -r requirements.txt
python XXCR.py config
python XXCR.py help
```
You can backup the files manually and it will likely go a lot faster than through python
