# XX Cutscene Replacer
A simple CLT for modding .usm cutscenes in Genshin, ZZZ and HSR  

## Usage
Install python, run:
```
git clone https://github.com/Epigeos-com/XXCR
pip install -r requirements.txt
python XXCR.py config
python XXCR.py help
```
[CriStudio](https://github.com/Youjose/CriCodecs) is useful for previewing the original files, and troubleshooting the modified ones
